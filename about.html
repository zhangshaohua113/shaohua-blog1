你好，欢迎来到韶华实验室！

这里记录着我的学习笔记、项目实战和踩坑经验。希望通过这些文章，既能帮助自己沉淀知识，也能给同样在路上的你一些参考。

我做什么

  • 嵌入式开发：STM32 / ESP32 / 51 单片机
  • 物联网应用：传感器、WiFi、MQTT、云平台对接
  • 工具链折腾：AI 编程助手、本地服务、自动化脚本

本站的技术栈

本站是一个零依赖的服务端渲染博客：

组成方案
服务Node.js 原生 http（零第三方依赖）
渲染服务端自研轻量 Markdown 渲染器
内容posts/ 目录下的 Markdown 文件，自动扫描成索引
前端原生 HTML + CSS + JavaScript
端口8766（start-server.bat 一键启动）

只需要装了 Node.js 就能跑，没有数据库、没有构建步骤、没有框架升级焦虑——这就是我想要的轻。

本站由 DeepSeek（DSH）与 opencode 协作完成：前者负责重构为服务端渲染版，后者完成了最初的纯前端版本。两版思路不同，各有取舍，欢迎对比着看。
